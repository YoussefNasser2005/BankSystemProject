# Simple Banking System in C++

## Description

A simple banking system project in C++ running in the console (terminal).

This project allows managing bank clients’ accounts through a user-friendly text interface, including:

- Displaying the client list with account details  
- Adding new clients  
- Deleting client accounts  
- Updating client information  
- Searching clients by account number  

Client data is stored in a text file (Clients.txt), enabling data persistence between runs.

This project is suitable for beginners who want to learn file handling, structs, and lists in C++.

---

## How to Run

1. Open the main.cpp file using a C++ IDE like Visual Studio, Code::Blocks, or VS Code.  
2. Compile the program.  
3. Run the program in the console (terminal) window.  
4. Follow the instructions in the main menu to manage client accounts.

---

## Requirements

- C++ compiler (like GCC or MSVC)  
- C++ compatible IDE (Visual Studio, Code::Blocks, VS Code)  

---

## Features

- User-friendly text interface  
- Client data stored in a text file  
- Full client account management: add, delete, update, search  
- Simple design suitable for beginners
