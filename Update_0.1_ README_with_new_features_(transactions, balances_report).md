# Simple Banking System in C++ (Updated Version)

---

## Description

A **simple banking system** project written in C++, running in the console (terminal).

This project allows you to **manage bank clients’ accounts** through an easy text-based interface, including:

* Displaying client list with details
* Adding new clients
* Deleting client accounts
* Updating client information
* Searching clients by account number
*  **Transactions**: deposit and withdraw money
*  **View total balances for all clients**

Client data is stored in a text file (`Clients.txt`), enabling data persistence between sessions.

This updated version is perfect for beginners who want to learn **file handling**, **structs**, **vectors**, and **menu-driven programs** in C++.

---

##  How to Run

1️⃣ Open `main.cpp` using any C++ IDE (Visual Studio, Code::Blocks, VS Code, etc.).
2️⃣ Compile the program.
3️⃣ Run it from the console (terminal).
4️⃣ Follow the main menu instructions to manage accounts and perform transactions.

# نظام بنكي بسيط بلغة ++C (نسخة محدثة)

---

## الوصف

مشروع **نظام بنكي بسيط** بلغة C++ يعمل في نافذة الكونسول (الطرفية).

يتيح لك هذا المشروع **إدارة حسابات العملاء البنكية** عبر واجهة نصية سهلة الاستخدام، يشمل:

* عرض قائمة العملاء مع تفاصيل الحساب
* إضافة عملاء جدد
* حذف حسابات العملاء
* تحديث بيانات العملاء
* البحث عن العملاء باستخدام رقم الحساب
*  **إجراء عمليات مالية**: إيداع وسحب
*  **عرض إجمالي أرصدة جميع العملاء**

يتم تخزين بيانات العملاء في ملف نصي (`Clients.txt`) لضمان حفظ البيانات بين جلسات التشغيل.

هذه النسخة المحدثة مثالية للمبتدئين لتعلم التعامل مع الملفات، الهياكل (structs)، القوائم (vectors)، وتصميم القوائم التفاعلية في ++C.
