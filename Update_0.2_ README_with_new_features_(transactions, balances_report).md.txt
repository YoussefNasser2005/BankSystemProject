
# Simple Banking System in C++

---

## Description

A complete console-based Banking Management System written in C++.

This upgraded project allows managing both **bank clients** and **system users** through a role-based access control system. It features:

* Secure login system for users
* Permission-based access for different operations
* Full client management: add, delete, update, find
* Transaction features: deposit, withdraw, view total balances
* User management: add, delete, update, and search users
* Persistent storage using text files for clients (`Clients.txt`) and users (`Users.txt`)

Great for learners who want to understand real-world file handling, user access control, and data structuring in C++.

---

## How to Run

1. Open the `main.cpp` file using any C++ IDE like Visual Studio, Code::Blocks, or VS Code.
2. Make sure `Clients.txt` and `Users.txt` exist in the same directory (or the program will create them).
3. Compile the program.
4. Run the executable in the terminal.
5. Log in with valid credentials and begin managing clients or users based on your permissions.

---

## Requirements

* C++ compiler (like GCC, MSVC)
* IDE or text editor supporting C++ (Visual Studio, Code::Blocks, VS Code)

---

## Features

* 🔐 **User Login System**
* 🛂 **Role-based Permissions for Each User**
* 👥 **Client Account Management**

  * Add / Delete / Update / Find Clients
* 💰 **Client Transactions**

  * Deposit / Withdraw / View Total Balance
* 👤 **User Management System**

## كيفية التشغيل

1. افتح الملف `main.cpp` باستخدام بيئة تطوير تدعم C++ مثل Visual Studio أو Code::Blocks أو VS Code.
2. تأكد من وجود ملفات `Clients.txt` و `Users.txt` (سيتم إنشاؤها إن لم تكن موجودة).
3. قم بترجمة الكود (Compile).
4. شغّل البرنامج عبر الطرفية.
5. سجل الدخول باستخدام اسم مستخدم وكلمة مرور صالحة، وابدأ بإدارة العملاء أو المستخدمين حسب الصلاحيات الممنوحة لك.
